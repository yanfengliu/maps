# Lessons

- Process ancestry alone does not establish ownership after Windows reuses a PID. A browser cleanup collector followed a reused crashpad PID into four older unrelated processes; Windows rejected every stop and unchanged creation identities confirmed they remained alive. The corrected temporary selector requires exact executable identity and child creation at or after its recorded parent, then rechecks each owned process before individual termination. Retiring gate: a retained shared cleanup selector/test that first fails on reused-parent, older-child and foreign-executable fixtures, then excludes them while retaining real newer browser/server children. The current ignored probe fixture demonstrates the fix but does not retire this lesson.

- A map click can select a building and replace the campus panel, so later probes must reset through the real overview control before expecting the Stanford/Main Quad actions. Two optional capture attempts assumed the old panel; the corrected real-control flow passed without changing the product. Retiring gate: reusable selection → overview → Stanford → Main Quad verification that first fails when overview no longer restores the expected controls. The current private successful flow alone does not retire it.

- A restored GeoJSON source does not prove its custom 3D layer survived graphics-context loss: MapLibre serializes standard layers only. The idempotent attachment path now recreates custom detail independently and passed actual loss/restoration with full readiness. Retiring gate: a reusable browser recovery check that first fails with the source-exists early return restored, then passes with the custom layer reattached; the current private successful flow alone does not retire it.

- Camera input checks must settle earlier animation before attributing a later change to a new control. The first auxiliary search-focus probe sampled an unfinished tilt; a settled comparison passed without a product fix. Retiring gate: a reusable real-browser input-isolation check with an intentionally ongoing prior flight, a stable pre-input pose and a wrong early-sample negative observed red. The corrected private flow alone does not retire that gate.
