## GPU continuation decision

The two-pass proposal is coherent and bounded: keep the same CPU root/ordered-foot owner and leg solve; upload its complete 53-joint palette; evaluate the complete influence law once per selected vertex into a position texture; compute area-weighted joined geometric normals from actual selected-triangle adjacency and those positions; let all selected parts read the textures by actual VAT ID. Offset/count plus a complete influence list avoids silent six-slot truncation. Temporary resources from the pinned ignored sidecars are sufficient; a public persistent schema is unnecessary for this proof.

A small equivalent simplification is to prepare the immutable per-vertex reference skin once and retain `deliveredIdle + correctedSkin - referenceSkin` in the GPU pass, so the shader need not reevaluate reference skin every frame. Algebraically precombining the idle/reference residual is also possible, but its floating-point ordering must pass the same CPU readback bounds. There is no need to introduce a different solver, generic GPU crowd scheduler or lower-body VAT blend. The proposed shared position texture is preferable to recomputing every adjacent triangle's full skinning independently for each normal.

Acceptance of the adapter still requires actual hardware floating-point target verification; all-selected-vertex position and normal readback against this oracle at startup, swing, landing, turn, transfer and cycle boundaries; contact observations on GPU output under unchanged limits; and failing omitted-seventh/ninth-influence and wrong-rig-frame controls. Bind selected ID, influence and triangle denominators, including UV-seam joins. Choose an omission witness whose effect actually exceeds the retained comparison bound, rather than assuming every very small weight can do so. Apply scale/root transforms exactly once, and preserve the current palette/sample identity across both passes and draw. Measure GPU passes, uploads and whole-frame cost separately. No performance acceptance is inferred here.

Then perform a short actual moving-loop native review through the normal controls at the preserved 1800 m overview, 620 m view and closer feet view, with sparse event samples and stated time gaps. Saved static poses cannot establish this. Current-primary integration, relevant gates and independent native review remain pending. The narrow source repairs can proceed independently of GPU implementation, but they must land in the candidate used for runtime acceptance.
