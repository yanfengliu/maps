## Native observation and source cause

I independently opened candidate3 `noon-close.png`, `noon-lower.png` and `dusk-close.png` individually with `view_image`, original detail, 1280×720. All three bytes/hashes matched the frozen index, before the probe's final result. The pane face has little broad visible structure; dark backs/returns, light floor edges and sparse cream objects dominate. The isolated dusk glint does not establish a continuous glass face. This agrees with the appearance failure in [1009](1009_commercial-native-rereview.md), whose cause was deliberately unresolved there. I did not inspect the other five originals in this branch or use current CPU tests as a visual oracle.

The concrete source mechanism is alpha-painted opaque PBR, rather than a thin transmitting slab. `src/scene/commercial-corner.ts:374` sets dark diffuse colour, transmission zero, a dielectric base plus clearcoat and constant opacity 0.42. Installed `three/src/renderers/shaders/ShaderLib/meshphysical.glsl.js:199–221` first adds diffuse/specular/emission and the clearcoat response, then emits that radiance with the opacity. `three/src/renderers/webgl/WebGLState.js:683–684` uses SRC_ALPHA / ONE_MINUS_SRC_ALPHA for this default non-premultiplied transparent material. Thus the room contribution is 0.58 everywhere, independent of incidence, and reflection already weighted by its BRDF is multiplied by 0.42 again. Dark diffuse tint cannot supply missing reflection structure.

The input to that reflection also has a finite bound. `src/scene/sky.ts:163–198` bakes a scene containing only a cloned analytic sky dome. Installed `envmap_physical_pars_fragment.glsl.js:22–40` reflects the view direction and samples that PMREM; it does not see the city. The sky provides a smooth vertical gradient, ground/haze colour, sun lobe and disc. Neither lower roughness nor another dielectric layer can recover absent street/building boundaries. This establishes missing incident content, not that city reflection is a required new subsystem or that complete-unit glass is impossible.

## One bounded construction and its discriminator

If root chooses the optical family, test a **single thin-slab composition in the existing upper-glass draw**, without coefficient search. Keep all geometry, actual source placement, source suppression, signs, ground materials, depthWrite=false, shadow exclusion, invisible/non-depth-writing GTAO normal, style switch and disposal contracts. Do not add a pass, atlas, sampler or light. Replace this upper pane's opaque diffuse/clearcoat accumulation with the following local equation in linear scene radiance:

`C = R(cosTheta, 1.5) × existingSkyIBLRadiance + (1 − R) × alreadyRenderedRoom`

Compute exact dielectric Fresnel and the slab sum above per fragment. Read the existing PMREM with installed `getIBLRadiance(geometryViewDir, geometryNormal, 0.06)`; it already includes environment intensity. Emit RGB `R × IBL`, alpha `R`; use explicit premultiplied source blending ONE / ONE_MINUS_SRC_ALPHA. Bypass the stock final premultiply to avoid multiplying by R twice. Remove the dark diffuse term and duplicate clearcoat contribution from this draw. Do not keep a fixed 0.42 opacity or add a brightness pedestal. Existing PMREM includes the sun disc; this bounded first construction does not add another direct-light term. A missing environment/hook must refuse rather than silently draw black. This is a complete local optical equation using an already working lookup, not an unsolved reflection renderer hidden behind a new API.
