## What the discriminator establishes

The native atlas already contains a soft, low-resolution but more recognizable `STARBUCKS COFFEE` word. Current 1007 retains 165 integer pixels and uses `max(118,bg+18)` selection. Faint strokes are below its absolute 118 floor even when distinguishable from their local background. The unprojected current-cell-mask image is already fragmented. The CPU current-shader approximation projects that pattern to x409–575/y379–406, matching the sign region and missing-stroke pattern in the native close original. The raw-colour control uses that identical cropped geometry and retains the more complete word. This is causal evidence against the mask's coverage, without needing scene lighting, a different crop, a changed font or a new texture.

At the close camera the local screen/source Jacobian singular values are 2.059/1.442 screen pixels per source pixel for Starbucks and 2.066/1.400 for south TSUTAYA. The source is magnified in both axes there. Lower views remain 1.448/1.253 and 1.607/1.312. Seed 1729 reaches 1.335/0.964 and 1.471/1.046, so minification starts to matter there. Block views compress one source axis to 0.206/0.193 screen pixels per source pixel. Close-view fragmentation therefore does not require minification, although later view degradation can add to it. This is local geometry/sampling evidence, not an installed GPU sampler or whole-sign frequency-response measurement.

The current close crop itself can carry recognizable word structure in the raw-colour control. No crop expansion is required to reproduce the source-versus-mask difference. Larger diagnostic boxes also contain photographic window structure, so their out-of-crop residual mass cannot be counted as missing letters. Current crop correctness at every boundary is not proved; specifically, the south TSUTAYA's final diagonal stroke near the right edge deserves native review. Changing crops alone would leave the demonstrated coverage loss intact.

For a concrete second mechanism, the probe estimates each column's RGB background as the 25th percentile within Starbucks box [280,3483,365,3502] or TSUTAYA box [345,3512,394,3537], subtracts that background from actual source samples, clips negative residuals and applies gain 3 over the existing dark backing. It then clips to the source-observed text bands: Starbucks 3487≤y<3498; TSUTAYA 3523−0.25(x−353)≤y<3533−0.25(x−353), within current crops. This removes much of the vertical photographic background without replacing glyph shapes. Under this explicitly declared background model, the current mask retains 54.9% of positive source contrast inside the Starbucks band and 70.0% inside the TSUTAYA band. These percentages are model-relative contrast measurements, not labelled glyph recall or objective readability scores.

Native diagnostic projections show more complete source strokes after subtraction. They also show soft noisy edges and residual bright structure, especially around south TSUTAYA. The 25th percentile is an image-processing estimate, not measured unlettered glass. Original glyph/background radiance is mixed in the source; this experiment does not uniquely recover that decomposition or prove exact typography from the photograph. Its sRGB arithmetic, bilinear sampling and centre-Jacobian derivative approximation intentionally omit GPU colour conversion, mipmaps/anisotropy, lighting, occlusion, postprocessing and helper-lane derivative behavior. The 1008 `fwidth` caveat is not established as a cause here.

## Bounded repair to test

Test source-derived background removal on the existing south sign draw, while retaining the current source atlas, source-coordinate clipping, opaque backing, exact placement and all east-sign/roof/advertisement preservation. Keep the sign openly identifiable as processed source imagery. Do not call it unchanged photographic lettering or replace it with an arbitrary font.

One economical encoding is a strip per source column inside the observed text band. Bake the measured background RGB into a declared vertex channel, interpolate it across each strip, and subtract it from the sampled source colour in the sign shader before compositing onto the opaque backing. A separate explicit label guard must leave the east sign's original map result unchanged. The existing vertex-colour channel could carry the background if its ordinary multiplication is bypassed only inside those two guards; otherwise a separately accounted attribute is required. Keep the desired colour-space operation explicit. Compute derivative widths before crop-dependent branching if any derivative antialiasing remains. This is an implementation proposal; the shader and lifetime/pass integration have not run.

`column-strip-cost.py` clips these actual 127 source columns against the two original south UV triangles and both text-band boundaries. It yields 170 Starbucks and 94 TSUTAYA triangles. Conservatively adding all 264 without deducting replaced south planes gives **10508 triangles/1699320 geometry bytes/8 draws/0 new atlases/1 existing light**, under the unchanged 12000/2 MiB/8/0/2 limits. The honest fallback is an explicitly authored, source-traced sign reconstruction with disclosed uncertainty, independently judged against the actual source; this report does not authorize a substitute font or claim such tracing has been done.
