Required sections are encoded independently with the existing descriptor graph encoder. Known completion records therefore contain their actual keys, scalar values, own/absent observations, stack observations, state and pin facts instead of only object IDs. Cycles use reference atoms. BigInts use typed decimal atoms. Symbol keys retain typed IDs. Accessors are described without executing getters. Proxy nodes stay explicitly opaque and are not reflected. The packet never sends raw source values into JSON.stringify. Failed section observation records `REQUIRED_OBSERVATION_FAILED` and stays HOLD rather than treating unavailable facts as success.

This is a bounded policy, not a claim that arbitrary internals can be reconstructed safely. Proxy internals, accessor return values and arbitrary function internals are unsupported. The current descriptor encoder has no explicit finite depth/node budget. Deep ordinary graphs may cause a caught section failure; exact known supported sections must still be complete for acceptance. General hostile-runtime mutation, out-of-memory failure and every final output medium failing are outside this proposal. Independent review should decide whether a depth/node budget is necessary for this finite producer population before source admission. Do not quietly substitute an opaque atom for a required known section.
