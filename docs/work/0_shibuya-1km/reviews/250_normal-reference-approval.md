## Mathematical finding

For the current outer transform `p_i = s (R q_i + b) + o`, with proper yaw rotation R and positive uniform s, a face cross product is `s² R cross(q_b-q_a,q_c-q_a)`. Summation and normalization therefore give `R normalize(sum cross)` before world translation or storage. All nonlinear or nonrigid skeletal behavior is already inside q; the proof does not assume rigid bones or replace their full deformation. The measured fixture uses positive scale `1.0391258001327515` and non-cardinal yaw in both inspected cases.

Define q exactly as the existing idle VAT point plus all normalized current skin contributions minus all reference skin contributions, with the original bind conversion, homogeneous reciprocal, current 53-joint palette and reference frame. “Source doubles” means those existing values evaluated as binary64; the idle VAT itself is half-float source data. It does not authorize replacing it with a supposedly more precise rest mesh. Accumulate each unnormalized incident triangle cross product once per original vertex incidence, in original face order, joined by the existing VAT ID. Keep seam duplication/membership and winding unchanged. Normalize the sum only once, then apply yaw. Retain the reference as binary64 or specify and bound any output storage conversion explicitly.

The correction changes two numerical choices: world-position rounding before the cross product, and Float32 rounding of each accumulated face sum. The former has the direct counterexample; the latter deliberately selects a more accurate evaluation of the same geometric sum. Call both out in the new reference version. It is not a threshold relaxation: compare raw finite GPU xyz normal values to this independent normalized reference with Euclidean distance at most `1e-5`, without normalizing the candidate in the comparator or substituting a per-component bound.

This normal transform is scoped to the stated outer transform. Reject unsupported nonuniform outer scale, shear, reflection or extra model transform rather than silently applying yaw-only normals. Such transforms require a separately specified cofactor/inverse-transpose and winding treatment. This condition does not prohibit the already evaluated internal skin deformation.

1. **Freeze an independent complete oracle.** Produce all 51 event/LOD reference buffers from the original source sidecars, source draw topology and original palettes. Assert exact selected-ID identity, triangle incidence/order, counts, every influence, 53 joints, and unchanged scale/sample/source identities. Do not derive the oracle from candidate positions, packed GPU inputs, uploaded normals, or a candidate-owned adjacency table. The current probes use frozen prepared adjacency; source-neighborhood checks here support it locally, not complete independence for the new producer.

2. **Prove rigid covariance with measured outputs.** Preserve the existing near/medium 2^-19 m counterexamples as old-law red controls. Exercise positive and negative x/y/z translations, a metre offset, and offsets crossing relevant Float32 exponent boundaries; their purpose is geometry invariance, not new pavement events. Compute both arms, rather than recording a literal expected zero. In `probe2.mjs`, `bodyLocalReferenceNormalChange: 0` is an algebraic declaration, not a measured second run. Check yaw zero, a quarter turn and an independently chosen non-cardinal yaw against independently computed unrounded world face sums; also test a positive uniform-scale transformation on a separate synthetic control. For finite nondegenerate actual cases, predeclare a tight binary64 control tolerance, such as `1e-9` Euclidean, distinct from the unchanged GPU bound. Preserve every failing row; investigate rather than tune the tolerance after seeing a failure.

3. **Show that correct normals cannot conceal a wrong deformation branch.** Before candidate scoring, review that normal generation consumes the same unrounded local deformed geometry used by its position path. A separate normal path supplied with clean reference values could pass while geometry is wrong; the 10 micrometre position tolerance alone permits perturbations that materially rotate these tiny faces. On a named tiny face, deliberately perturb one local source vertex by no more than 10 micrometres, measured to produce a normal discrepancy above `1e-5`, and require the independent normal comparison to reject it while the reference stays unchanged. Add reversed winding/omitted incident-face controls and a wrong-yaw control. The intended final world-Float32 quantization is specifically excluded from this local-geometry coupling requirement; the correction exists because demanding normals of that quantized surface reproduces the conditioning failure.

4. **Retain complete influences and frame controls.** The lossless ninth-slot permutation must pass first with every selected vertex and normal; only then is its material ninth-slot omission meaningful. Keep the material seventh-slot omission, all three wrong-frame controls, all events/LODs, actual maximum neighborhoods, complete readbacks, finite available/non-disjoint GPU timings, 10 micrometre world-position, 15 mm pavement penetration and 5 mm planted drift requirements. The existing comparator uses strict `< 0.005` for drift; do not silently loosen that boundary. None of these controls inherits a pass from a failed predecessor. A plain local-Float32 implementation is already unproved: family A reports near error `4.389926797959377e-5`, with 118 vertices over the bound.

5. **Use a genuinely withheld control after the mechanism is frozen.** A reviewer should choose and retain at least one undisclosed non-cardinal yaw/translation combination and a source/palette perturbation with a measured material normal effect, including far LOD and an influence-bearing vertex outside these published witnesses. Freeze identities before revealing the inputs, then run the same complete comparator. This supplements, not replaces, the 17-by-three fixed benchmark. These already published probes and named witnesses cannot be called blind or withheld. Do not pretend any reviewer-selected withheld case has already been prepared here.

These are completion requirements for the new instrument, not findings that the mathematical correction itself is wrong. The decisive failure mode to avoid is replacing the old independent geometry requirement with agreement between two candidate-derived values. Accurate smooth normals of the unrounded target surface are a sound rendering target, but accurate normals alone do not establish silhouette, visible lighting, contact continuity or natural gait.
