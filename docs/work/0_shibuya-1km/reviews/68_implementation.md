## Reports

**Accept the F35 amendment at the design level. Recommend that root mark F35 resolved as a design finding and consider the separately scoped implementation stage.** No remaining fundamental blocker was found for this bounded first pipe proof. This is not implementation correctness, Node binary compatibility or execution approval.

The critical source-specific hazard is now handled explicitly. In the pinned [Node24.12.0 implementation](https://raw.githubusercontent.com/nodejs/node/v24.12.0/src/node_api.cc), Push refuses a full queue without taking the payload; closing consumes one producer count. Release consumes its own count. Finalize calls the addon finalizer before EmptyQueueAndDelete invokes queued callbacks with null env/callback. Hook removal deletes its wrapper and schedules later environment bookkeeping. Relevant frozen lines are240-262,277-304,426-432,807-815 and851-856. V2 keeps producer/controller TSFN authority separate from native memory leases, retains caller ownership on refused enqueue, and forbids a second release after closing consumes authority.

The accepted-payload lease protects both bytes and callback context through the complete callback frame. The channel finalizer releases only its own lease. Instance, hook and joined-producer leases cover their separate users, with no assumed ordering between instance and channel finalizers. Thus a finalizer receipt cannot free the context still used by queued null-env disposal. Destruction is gated on every lease and active frame ending; no code may use the block after its last release. This addresses the concrete lifetime hole that a generic reference to an async cleanup hook left unspecified in v1.

The hook's dependency order also addresses the join cycle. It first stops acquisitions and nonblocking callback production, settles I/O with live storage, and joins the producer through dependencies that need no JS or channel finalizer. The environment-side controller then retires its distinct channel authority. Hook removal stays on the environment thread and does not wait for queued disposal, later finalization, JS promise settlement or block destruction. The observer combines those later receipts. A stalled native join remains nonfinal, with separately recorded rescue; it cannot become success at a deadline. The later implementation review must confirm that its locks, diagnostics and failure exits actually preserve these dependencies.

N04 now exercises the missing environment boundary instead of simulating a stop. One test Worker uses the same addon/native pipe body while its parent Node host and native outer owner remain alive. Two fixed peer values identify two accepted queued payloads. The same-turn Atomics.wait barrier prevents JS callback delivery; a separate native acknowledgment avoids consuming another callback slot. The outer driver must observe both pending read/write operations, both accepted IDs with no callback entry or terminal result, their outstanding leases and live original peer/host handles before issuing the termination trigger. Merely naming these states is not proof: missing or already-settled checkpoints fail or remain unavailable.

The receipt sink is the live host's borrowed native stdout writer, serialized in C++ and drained by the outer driver. It survives Worker teardown and cannot be closed, canceled or inherited as a Worker-owned transport. The host emits no competing stdout during the native phase. A blocked or broken receipt stream makes the evidence incomplete. This is a bounded test witness, not a new production IPC authority or a substitute for retained process handles.

The parent calls actual worker.terminate without a preceding ordinary JS stop. Node documents termination as asynchronous and reports the Worker's exit code when its exit event occurs; this is distinct from the parent process status. [Versioned Worker contract](https://nodejs.org/download/release/v24.12.0/docs/api/worker_threads.html#workerterminate). N04 requires actual native hook, operation, producer, channel, payload, instance and destruction records after the trigger while the original host handle remains unsignaled. It specifically requires the channel-finalizer record before both null-env discards and block destruction after all final accesses. Matching fixed peer values through raw wire and stable payload IDs prevents an aggregate zero from standing in for disposal. Supplemental corrupted records test the checker but cannot replace that native sequence.

Destroyed-environment promises are explicitly abandoned by environment teardown, not claimed settled by JavaScript that can no longer run. Native completion remains mandatory. After scoring, the host's keepalive/input is released and its natural process exit is joined. Whole-host kill, ordinary JS stop, an empty queue, an already-completed write, process.exit, synthetic hook invocation or rescue cannot pass N04. C01 independently gains actual natural Node exit after normal drainage, excluding forced exit and an early TSFN unref workaround. This checks the ordinary referenced-channel lifetime separately from forced Worker environment teardown.
