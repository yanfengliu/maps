3. **Certify whole intervals and endpoint stars.** Build strata from expected and actual cell boundaries, all finite intersections and every domain/facet/patch/replacement transition, including coplanar zero-area contacts currently skipped by surface-interiors. For each open interval, evaluate each domain constraint at both endpoints: a nonzero affine sign is strict throughout the open interval, while both-zero constraints stay active. This establishes an invariant local germ; a midpoint is not the proof. Restrict active constraints to a rational transverse square. Its cyclic boundary must have one occupied arc and one exterior arc, exactly two selected outward transitions, and opposite directed patch incidence with correct labels. At each endpoint or isolated corner, clip the active linear constraints on the six faces of a fixed direction cube. This uses the same planar clipping, not a new general solid engine. The complete occupied/exterior cell complex must be regular, each side edge-connected, and their common boundary one simple cycle with degree2 and no crossing, isolated, pinched or branched strata. Match every selected patch germ once. These active-constraint links are exact local statements; no numerical epsilon or uniform sampling radius is used.
