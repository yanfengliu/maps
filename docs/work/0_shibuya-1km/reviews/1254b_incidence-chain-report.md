## Mechanism and proof boundary

1. BTables reconstructs the complete source constraint/formula tables through MakeBasis, then checks identities, coefficients, use records, every term/relation, occupied constraint index, kind, dimension and evidence. The existing endpoint/all-vertex uniform-sign argument proves the whole relative-interior label, including boundary versus strict occupancy. Representative points are checked witnesses only.

2. BCarriers derives the complete finite one-dimensional obligations from every source region boundary, every source segment, every nonempty full affine equality chord through the pane and the caller's pane-boundary mode. It also derives all source endpoints and singleton/tangent events. It constructs no expected2D cells. BCover requires an exact consecutive chain of supplied atoms on each whole carrier, without filtering by physical labels or participants. Every supplied atom must lie entirely on a source carrier. Physical-boundary, pane-boundary and partition-constraint references are recomputed in full, including different source constraint indices sharing one chord. Thus a pure proof-partition interval has the same coverage obligation as a physical contact interval.

3. BIncidence requires all source seeds, atom endpoints, cell vertices and every cell-edge intersection in the node ledger. It examines every pair of supplied atoms with exact SegmentMeet, forbids positive-length overlap and requires each intersection to be a common declared endpoint. It forbids an atom spanning any declared node or cell-edge event. Complete carrier coverage plus atom intersection closure implies every source-carrier crossing is present: each carrier covers that point with an atom closure; the atoms meeting there must have a common endpoint and corresponding node. An isolated or extra supplied node must come from a source seed, an atom endpoint or a cell vertex. This is a finite explicit incidence test, not a helper assumed to recover the missing population.

4. Every supplied cell is a nondegenerate convex finite polygon inside the convex pane, with the pane's orientation. F rejects duplicate vertices, nonplanarity, reversed edges and nonconvexity. BCellCoverage splits all supplied cell/pane edges at a common complete node set and compares their exact oriented1-chains. Endpoint and intersection existence was checked independently before using that supplied set for splitting. After normalizing by the pane orientation, the winding number of each convex cell is its interior indicator. Equality of the summed boundary chain to the pane boundary therefore makes the indicator sum one off the finite edges. All indicators are nonnegative, so overlaps and holes are impossible. Finite closed-cell closures also cover every boundary point. Area conservation remains a diagnostic and certificate field, not this proof's premise.

5. BTree checks the declared binary tree's reachable identities, constraint references, complete leaf paths and each leaf polygon's correct weak side with a strict point at every ancestor split. Combined with the already-proved whole-pane coverage, these side constraints prove each tree branch covers its actual halfspace portion. No parent or expected leaf polygon is reconstructed. Each whole source formula is uniformly signed on every cell; complete pane coverage therefore gives complete source-region area classification. Complete carrier chains give complete1D/0D classification and all endpoint facts. The returned coverage records retain the old shape. If coverageCertificates exists, every region, Boolean, edge and atom/cell reference is checked semantically against the newly derived coverage. Absence of the optional field cannot bypass geometric/incidence checks.

This proof reuses the frozen exact finite/rational kernel, including F convexity, Clip, SegmentMeet, SignCertificate and FormulaMembers.
