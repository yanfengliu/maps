## Design and implementation

`DESIGN.md` records the accepted formulation and its bounds. Each nominal shoe/support intersection now has an inner region clipped against the support edges and normal band inset by the supplied vertex uncertainty plus the existing arithmetic guard. Barycentric combinations preserve the maximum vertex-error bound. Orthogonal projection onto a fixed selected plane and then X/Z projection are nonexpansive. Each inner point therefore has an actual contact counterpart within that bound. A passing hull uses only resolved positive-area inner regions and requires the exact supplied load query to lie more than epsilon inside every hull edge.

The outer region expands those same inequalities. Every possible actual contact has a nominal preimage inside it. A definite hull failure requires the load to lie farther than epsilon from the complete outer hull; an empty outer set also fails. The interval between inner and outer decisions is uncertain. Point and segment outer hulls remain possible contact evidence, and required banks use resolved inner presence versus possible outer presence. This avoids division by the nearly parallel plane angle that amplifies the contact-boundary movement.

`patches` and `nominalHull` preserve nominal geometry separately. `innerPatches`, `outerPatches`, the passing `hull`, `possibleHull` and `possibleHullDistanceM` expose the actual decision bounds. A nominal patch's `verdict` describes only the existence of a resolved inner region, never a promise about its nominal boundary. Empty possible hull distance is null, not a silently serialized infinity. The API now explicitly states that `loadPoint` is the exact supplied query and `packingErrorM` describes shoe vertices only. No unstated second load-point uncertainty is consumed. The 15 mm contact and 5 mm drift thresholds are unchanged.
