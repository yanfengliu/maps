## Implemented boundary

`createWalkingSurfaceQuery({ roads, pavements, terrain, sceneManifest, osm, networkSha256, historicalNetworkOsmSha256, maxAnchorResidualM })` verifies SHA-256 against copied bytes and keeps configuration/digests stable across asynchronous hashing. Each byte input is `{ bytes, sha256 }`. The query uses strict current triangle coverage, excludes the verified manifest's appended terrain cap suffix, and derives current walking-way eligibility using the existing network producer's OSM filters. Expected-byte equality is not source-policy approval. `begin(source, XZ, previous?)` chooses an interval; `trace(interval, contact, endpoint, sourceYFrom)` returns actual Y, normal, mesh digest/triangle identities, or named missing/ambiguous/changed/covered-source refusals. An interval belongs to its query. It cannot fill a missing selected road sheet with terrain. All level-change refusals retain previous and candidate contacts for inspection.

`buildWalkingPath({ route, surfaces, maxSegmentM, joinWindowM })` preserves graph choices, edge occurrences, passages, gates, source starts and seeded offset arrays. It materializes interior sampler boundaries and bounded occurrence connectors, checks centre containment in the local source-corridor capsule union, preserves returning tips, fits Y before measuring 3D arc, and carries monotone local source station separately from physical arc. It preserves terminal XZ, offset and yaw, while Y comes from support. Tangent changes are explicit geometric stop/turn events. All paths return `productionReady: false`; turn events return `locomotion: "unverified"`.

`sampleWalkingPath(path, physicalM)` samples the final physical polyline and coherent contact position. `advanceWalking(path, state, dt, speed, yawRate, authority)` consumes physical travel and turn time separately; pivot travel and source progress stay unchanged. Authority supplies the existing same-tick source hold plus all applicable unheld original disk primitives, owner identities and actual rectangle dimensions. The earlier source hold or conservative continuous rectangle contact stops movement, including intermediate rotation and the next distinct owner. The caller still owns passage/lease decisions. No lease v1 or v2 implementation was imported.

## Remaining limits and next scope

This is a bounded geometric candidate, not production-ready motion. Corridor checking covers the centre only; a rotated whole-body/sole corridor proof is absent. Authority sweeps cover the caller-supplied rectangle/disks, not actual skinned soles. Every tangent change can generate a stop/turn, which is not accepted gait. The existing Review40 pivot evidence remains red. Seam-foot proof and step locomotion are not implemented; strict failures remain. `maxSegmentM` controls source-station chord sampling inside retained sampler segments, not an independently established physical approximation error. Arc/speed bounds apply to the materialized final polyline.

Initial interval selection still uses nearest source-Y anchor inside an explicit search range plus current source facts. It is exploratory evidence, not a reviewed source-to-surface interval policy. In particular, current walking-way tags alone do not prove that a lone ground hit at a missing road anchor is the intended historical support interval. `productionReady:false` and historical-eligibility status prevent an accepted path claim. A production boundary must provide reviewed occurrence/interval source-level facts with provenance; it must not acquire raw OSM in the browser. The existing producer already filters source ways and emits `sourceWayId` in `tools/network/generate.ts:32,44,210`; a small producer-owned fact record can preserve the relevant filter/source-level facts and their source digest. Current tags must not be backfilled as historical evidence.
