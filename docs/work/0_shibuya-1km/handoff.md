## 4. The workflow that worked here

- **Orchestrator + goal mode, with lanes as subagents.** The main thread reads enough to write an assignment and to accept or reject a handoff; it does not implement. Every code change went to a lane with: owner, outcome, base revision, workspace, allowed and excluded paths, verification, resource limits, and the exact shape of the report wanted.
- **A visible task ledger.** Keep a `todo_write` list of the steps to the goal and mark items done as lanes finish — the owner asked for this explicitly and made it a fleet rule.
- **Land immediately, in the same session.** Merge the lane's branch to main, run the gates, push. Work sitting on a branch does not count, and the tree is thrown away when a thread is archived.
- **One expensive gate at a time.** `npm run visual` owns a port and the whole machine. Timing measurements must not overlap each other or a capture: two timing lanes on one loaded box produce two wrong answers.
- **Lanes work in worktrees** (`artifacts/<lane>/wt`, with `data` and `node_modules` as junctions to the primary created by `cmd /c mklink /J`). **Never remove a worktree without unlinking those junctions first with `cmd /c rmdir`** — an earlier session ran `git worktree remove --force` without that step and emptied the primary's `data/` and `node_modules/`. Enumerate the worktree's ignored files before removing it: lanes write evidence under `<wt>/artifacts/`, which is invisible to `git status` and to any ancestry check, and one cleanup destroyed paint-review and frame-budget evidence that reviews cite by digest.
- **Verification rules that paid for themselves repeatedly tonight:** a lane's exit-status claim is about the lane's tree, not yours — re-run the gate on the merged revision (`npm run typecheck` was reported green by a lane and was red on main); read a gate's output whole rather than through `Select-Object -Last 2`, which hid four of six type errors; a mutation arm proves nothing unless the file it writes is inside the lane's own worktree (one lane's script wrote into the primary and broke a tracked test file); and a check that can find its own needle is not a check (three separate self-satisfying checks were found tonight by two lanes).
- **Reclaim scratch at every opportunity**, and preserve evidence before deleting anything a tracked document cites.
