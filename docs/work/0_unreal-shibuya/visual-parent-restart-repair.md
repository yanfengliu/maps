# Parent-package restart admission repair

Round21's R27 found that the ignored material verify driver checked engine/plugin parents only within each process. It did not bind newly discovered parent path/digest inventory to the successful apply receipt. A changed shader parent could therefore be admitted across restart while named photo parameters remained equal. The coordinator independently compared the actual retained apply/restart receipts and found both real parent inventories equal; this observation does not repair the missing code contract.

The driver now requires a nonempty, well-formed exact absolute parent path/SHA256 inventory equal to `engine_or_plugin_parent_sha256_final` from the successful apply receipt before admitting fresh own shader statistics/readback. The comparison and successful apply receipt digest are recorded separately from within-process checks. Missing, changed and new parents are rejected. The final receipt also records the complete project-package difference from the original operation baseline, including authorized material saves; the existing final unexpected-drift check remains separate.

The source-bound offline control harness is ignored `artifacts/unreal/nanite-materials/test_parent_inventory.py`. It executes the actual original and repaired driver admission blocks with only the native resource call mocked. The exact retained real apply receipt supplies both parent names/digests. Each changed/missing/new-parent control reaches the original driver's native resource call and is refused before that call in the repaired driver. Additional controls reject missing/malformed apply inventories, admit the actual unchanged inventory and check that total package differences include allowed saves. No engine package was mutated and no native process launched. The original driver and all prior native receipts remain retained.

This repair changes the driver hash, so its strict project-input link cannot reuse the old apply receipt unchanged as a new native verification input. A later approved native exercise needs a pair produced by the repaired exact driver, or a separately reviewed explicit code-delta admission. No such allowance is silently introduced. Focused review and any new native dispatch are coordinator decisions; the measured photographic-tone block failure remains open.
