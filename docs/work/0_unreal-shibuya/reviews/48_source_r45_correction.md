[IsProcessInJob](https://learn.microsoft.com/en-us/windows/win32/api/jobapi/nf-jobapi-isprocessinjob) tests the process handle against a supplied exact Job; a null Job tests membership in any Job and is insufficient here. This is a source-inspected race counterexample, not an executed PID-reuse reproduction.

Required correction: before admitting any handle acquired from a queued PID, require successful `IsProcessInJob` against the still-open owned Job and a true result. On false/error, close that newly opened handle, retain the refusal and do not add a member or claim ownership success. Keep the exact handle held through accounting and cleanup. No test needs a broad process kill or real foreign-process termination.
