## Proposed correction contract

Use three dependency lanes in the existing task, not a new framework: artifact construction/admission; verifier regression qualification; actual native observation/acceptance. A fresh geometry or source change invalidates the first lane and downstream native assets. A verifier change invalidates the relevant regression family. A lighting/input change does not automatically invalidate the unchanged geometry constructor or require another fixture relocation.

For Source, replace the custom runtime-object profiler on the acceptance path with a small isolated execution boundary using the existing owned-process primitives: exact interpreter/install/source pins, controlled import roots, no user-site or preloaded selected modules, no bytecode writes, and guarded reads whose consumed bytes are the pinned bytes. Record actual loaded module locations and dependency identities; refuse foreign modules. Pin/check the relevant vendor installation once for that run/revision. Keep live filesystem ancestry/ownership checks at every actual I/O boundary. Do not reuse a mutable path verdict, a warm module object, or a mere mtime as an authority. This is a proposed implementation contract, not a demonstrated secure replacement.

Run helper fault-injection suites once per exact helper/dependency change and retain their immutable evidence. Rechecking the current evidence's identities is separate from reexecuting the suite. Reuse does not assert that a later process cleaned up; each actual process must still supply its own cleanup, failure and output evidence. Preserve the original source/native packets as rejected or bounded experiments. Do not refresh their hashes or relabel their failed clocks.

Keep all 80,000 original parents and required source roles for full geometry admission. The installed-package census is not automatically the executed dependency set: S/authority-final.json includes NumPy test/f2py/typing-test modules among 564 available modules, with a separate 3,383-entry runtime census. Removing unexecuted members from repeated work needs an explicit closed import-root/loaded-dependency contract and independent review. It cannot be justified by assuming the 85 Python/2 native modules observed by normal24 cover every future production import.

The exact historical phase clocks are experiment constraints. Finite process/output/allocation limits are real obligations. Retire an obsolete experiment and freeze a new bounded whole-command comparison before candidate execution; do not loosen its existing clock to make a candidate green. Count source admission, imports, construction, checking, output readback, failures and cleanup, plus orchestration overhead, in the new comparison.
