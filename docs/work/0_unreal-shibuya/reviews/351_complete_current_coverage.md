# Physical coverage must use the complete consumed surface

Bounded read-only contract judgment: YES. The no-hole test should compare each deleted parent's native XY footprint against the union of all CURRENT admitted consumed terrain and road faces. This includes retained terrain, every admitted neighboring fragment, inferred fill and the current full road replacements. Coverage is physical set membership; a covering face need not have the same parent ID as the footprint being checked.

The current validate_local_geometry coverage loop, support_source3.py:703–718, limits terrain candidates to fragments[parent_id], then adds current roads/inferred fill. Consequently it can report an uncovered area even when another already-admitted saved terrain fragment or retained face physically covers it. The contract calls for one complete consumed terrain, permits explicit bounded shared-edge stitches, and validates each fragment's own source ancestry separately. It does not require a parent's original XY domain to be covered exclusively by its own descendants. The candidate population should therefore be corrected; this is not permission to forgive a true hole.

Required protections and limits:

- Use only exact current output geometry that is actually consumed and saved: the complete derived terrain plus all current consumed road GLBs. Exclude the removed parent, superseded roads, unused patch faces and recipe/reference-only geometry. Retained faces qualify only if actually retained in that output.
- Preserve assemble/readback, fragment parent/interpolation/UV/NORMAL/winding, per-vertex stitch bounds, inferred anchors, region coverage, deletion inventories and raw/parent immutability. A neighboring fragment keeps its own ancestry; coverage must not relabel it or replace those checks.
- Spatial candidate filtering must include every face whose native XY footprint intersects the target. Adjudicate residuals in the specified actual float32-centimetre geometry with exact arithmetic. Every genuinely positive uncovered area still fails, regardless of magnitude. No epsilon, expanded polygon, query snapping or omission of a troublesome parent is justified. An exact-zero projected target has vacuous XY area coverage, without removing its independent geometry/conservation obligations.
- This predicate proves projected XY coverage only. Height/occlusion, continuous contact and grade, whole corridor/body support, native collision and performance remain separate checks. A covering projection cannot itself certify those properties or substitute for their failures.
