In live_io_tiny.py lines 98–104, cache_absence first checks the parent, then catches OSError around a second full root-to-leaf guard.check(path). C2 — A late exited child can be accepted before the hard-10 check. In tiny_caller.py lines 30–31 and 48–59, the timer starts before the two host pin reads and Popen. Each loop drains both streams and accepts poll()!=None before examining elapsed time. If pinning, process creation or a scheduling delay consumes the remaining allowance and the child has exited by the next poll, the code records held-child-exited-zero without checking that elapsed is below 10. A zero-exit child can consequently have held wall_seconds>=10. The external 45-second limit covers the complete parent invocation but cannot establish the distinct 10-second child verdict.
