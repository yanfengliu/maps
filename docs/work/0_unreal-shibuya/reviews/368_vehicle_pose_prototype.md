This is an unintegrated bounded prototype for root review. Product files, data, Git, C/S native outputs and engine state remain unchanged. No engine, compiler, source import or spatial index was run.

The current product renders the full car using one segment tangent plus one cross-section roll. The replacement computes one rigid height/pitch/roll from the complete six tested body-plane points and four actual tyre-bottom points. Legal route centre XY, heading, scale, dimensions and occupancy are unchanged. The current circular tyres lie on local Z=0 at (+/-1.35,+/-0.78)m for every spin, matching the actual WheelPart/PhysicsSnapshot construction; body points remain (+/-2.2,0/+/-0.9)m. A changed tyre or mesh needs this contract rechecked.

`pose_prototype.py` is an executable pure Python geometric prototype and guarded retained-road probe. An unused C++ export was removed after root's request to hold that preparation. No C++ candidate is retained or certified.

The support callback returns the actual first hit in the immutable original profile-reference interval [Z-1.0m,Z+0.8m], plus its native normal and source eligibility. It must report the first hit even when that hit is ineligible; it must never retry lower layers or change the interval to accommodate the fit. Native collision actor/component must bind to the already admitted current prepared surface source, with building, non-ground, unsupported layer and legal swept-footprint exclusion checked. A nearest route segment, old width or normal alone cannot establish that eligibility. This callback is a required missing adapter, not something the prototype proves.

At each of four fitting passes the solver queries actual pitched/rolled XY for all ten contacts, solves three-variable least squares, and centres the residual range vertically. The fifth query pass checks the returned rigid pose without another fit. The original reference is used for every query. Acceptance requires every contact gap<=0.20m, normal.Z>=0.7 and total plane grade<=0.2. Missing or ineligible support refuses. There is no population reduction, vehicle shrink, gap waiver, heading adjustment, XY jump, layer climbing or harness-verdict change. The fit is sufficient, not complete: it can refuse a footprint for which another plane could pass. Refusal must remain visible and admission red.

The limited retained-road probe decodes baked GLB vertices, rounds native coordinates to float32 centimetres and brute-force queries only the relevant pinned road. It builds no spatial index and imports no product Python. All four retained native impact gaps match within 2.0e-13cm, including the corner outside the original corridor. Old vehicle pose coordinates agree within 7.3e-12cm. On all ten points after fitting the maximum road gaps are 4.584838493cm for vehicle-loop-12 and 5.701056320cm for vehicle-loop-13. Synthetic checks cover an exact slope, crest OLD31.905110173cm RED/NEW3.749128721cm, outside-corridor refusal at a turn, steep grade, low normal, missing contact, unfit body overhang and immutable query reference. Sixteen assertions passed in the 0.1550697s geometric run. Read result-v1.json for literal operands; the two road-only results provide no global terrain/building first-hit or legal swept-ground admission.

Native must check actual first-hit source/triangle membership in that domain and whole oriented footprint containment before using a fit. Each contact retains its immutable reference, first-hit identity, point and normal; no fit result can create eligibility. Missing domain, incomplete sweep, unsupported area or ambiguous layer refuses. Publishing this domain needs Source-owner agreement and review; simply widening `width_m` or extrapolating profile heights is not the contract.
