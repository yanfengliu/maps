# Architecture references — 2026-10-20

Bound: a stylized, source-aware campus model, with a dedicated Memorial Church exterior and photo-grounded corrections to the Main Quad, Hoover Tower, Bing Wing and Roble Hall. This is not a survey of all 648 footprints. The reference photographs were inspected as rendered images in an owned headless browser, then compared with native map captures through real search, zoom, rotation and tilt controls. No source photograph is shipped as a texture.

## Source coverage and composition

The pinned dataset contains 648 building and building-part features, 87 level tags (86 positive and one explicit zero), 81 height tags, 58 roof-shape tags and 41 roof-height tags. It contains no window-count tags. Recorded levels drive facade rows where applicable; absent levels stay estimates. Roof, step, bridge, stadium and special tower/church parts do not acquire invented positive storey counts. Mapped roof shapes take priority over profile-based roof estimates. Exact per-building window counts remain unknown.

The original Main Quad outline includes the church's footprint. Extruding both caused generic Quad windows and roofs to cover the church's lower volumes. Render preparation now subtracts the church part from the Quad using only retained source vertices. The original public GeoJSON bytes, input objects, tags and height provenance are unchanged. One original courtyard opens to the exterior in the composed footprint, so the derived polygon has six enclosed holes; all seven original courtyard areas remain empty. Independent triangle-intersection checks validate the actual overlap removed, the retained Quad area and courtyard coverage. Unsupported source topology fails with an explicit diagnostic instead of inventing intersections.

## Verification bounds

Geometry checks cover source-property preservation, finite vertices within source vertical envelopes, church roof vertex containment, small facade relief, the emitted three portals/seven front openings, mapped and explicit-zero floor handling, the Roble/Bing profiles, courtyard coverage and the 150,000-triangle budget. Independent review found about 0.1607 m² of roof-triangle overhang across concave footprint edges despite vertex containment; this small modeled approximation is not claimed as exact polygon containment. Reintroducing generic church shading, generic floor repetition or the overlapping Quad composition makes focused regression checks fail; restoring the implementation makes them pass.

Native visual evidence and reference image screenshots remain under ignored `artifacts/stanford-landmarks/verification/`. The final map captures include fixed front, side, rear and overhead church views, an exploratory oblique view, campus/Quad/Hoover/Bing/Roble views and a mobile detail card. Frame intervals describe MapLibre render events during real camera motion on the named viewport/GPU; they do not measure physical display refresh. The integration owner records final gate results and exact inspected digests with the integrated review.
