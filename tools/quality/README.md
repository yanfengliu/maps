# Campus realism audit

Run `node tools/quality/audit-realism.mjs` with Node 24. It writes ignored `artifacts/realism-audit/realism-audit.html` and `.json`. `--repo PATH --out PATH` can audit an integration worktree from another checkout. The default builds the real complete campus exterior mesh and reports packed GPU geometry bytes against 24 MiB, two mesh buffers and the triangle cap; textures, church interior and live frame performance are separate. `--skip-geometry` is explicitly reported as not run.

The searchable report inventories every pinned source part, including unnamed structures; source height, floor/roof provenance, current architectural treatment, reference observations, limitations and unresolved risk families stay visible. Exit 0 means the inventory, reference claims, source-property preservation, name-invariance and resource checks passed. It never means that the campus is realistic. No unreferenced building is upgraded by a successful render or topology test.

Before accepting a modeling change, run the report, inspect the relevant reference photographs, compare fixed front/side/rear/roof views and an oblique view through real controls at native resolution, then fix the mismatches and repeat the changed views. Include every changed family and previously unknown large/landmark buildings; do not sample only attractive landmark fronts. Record missing ramps, doors, roof forms and facade proportions as unresolved, not as verified details. Run the existing roof, geometry and interaction gates independently. The report's all-part backlog identifies what still lacks evidence; it is not an automated image-recognition judgement.

Optional `--comparisons PATH` (alias `--reviews`) accepts a JSON array of reference-to-render comparisons. First run without comparisons to obtain `modelDigest`; it binds all files in `src/`, `public/` and `package-lock.json`. Each comparison has `ids`, `referenceKeys`, `modelDigest`, `result` (`compared`, `partial`, `pass-with-limitations` or `needs-work`), `reviewedAt`, `reviewer`, `notes` and `views`. Every view has `label`, a `path` relative to the manifest, and exact file `sha256`. The audit checks those bytes, the current model digest and reference bindings. Use `needs-work` when a photographed feature is still wrong. These states record bounded visual comparison, not whole-building photorealistic acceptance; observations and remaining estimates stay in the reference register. Image captures alone cannot supply a photographic source. A changed model invalidates old comparisons until the affected result is re-inspected; do not merely replace its digest.

Example comparison object: `{"ids":["way/232841898"],"referenceKeys":["roth-garage"],"modelDigest":"COPY_FROM_CURRENT_AUDIT","result":"pass-with-limitations","reviewedAt":"2026-11-08","reviewer":"Integration owner","notes":"Compared open decks; internal ramps still absent.","views":[{"label":"front oblique","path":"../browser/roth.png","sha256":"SHA256_OF_IMAGE"}]}`. Wrap it in an array and pass the saved file via `--comparisons`. Use IDs that are actually visible in the inspected captures; a wide campus image alone is not a comparison of all its buildings.

Add new references to `realism-references.mjs` only after inspecting the actual reference. Record source URL, source/photo date (or undated), review date, observed features and limitations. `photo-supported` is partial observational support; `document-supported` does not imply a photo match; `inferred` and `prior-review` remain distinct. Grouped stadium/tower parts share a source, so part counts must never be advertised as numbers of individually verified buildings. Source changes require reviewing the pinned 648-part expectation and stale reference IDs.

Run the focused regression with `node --test test/realism-audit.test.mjs`. It proves missing parts, falsely labelled evidence, discipline-name glass inference, modified source heights, stale comparison captures and GPU overflow fail, while known photographic backlog stays visible.

Generate the retained real-control probe with `node tools/quality/create-realism-probe.mjs artifacts/realism-audit`. Build first, start an owned hidden production preview, and open its URL using a named headless Playwright CLI session. From the output scratch directory run `npx --yes --package @playwright/cli playwright-cli -s=YOUR_SESSION run-code --filename=probe.js`. The probe captures fixed and opposite views for the reported locations, seeded views of other building families, church textures/ceiling/recovery, WASD and phone/globe transitions. Its observations include actual GPU bytes, draw calls, upload slices and motion frames. Inspect the images; no capture is automatically approved. Always close only that session and its owned browser/server descendants in a finally path, as required by AGENTS.md.
